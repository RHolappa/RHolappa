# Risto Holappa

Senior full-stack developer and founder based in Oulu, Finland. I focus on AI multi-agent workflows, practical automation, and agent-to-agent systems: how agents coordinate, use tools, and hand decisions back to people. I care about clear responsibilities, observable handoffs, and results people can review.

[Website](https://ristoholappa.com/) · [LinkedIn](https://linkedin.com/in/rholappa) · [Email](mailto:risto@willit.fi)

### Current focus

- **Multi-agent workflows** — Give each agent a defined job, input, and output so work can move between them reliably.
- **Practical automation** — Connect requests, tools, and data with checks and human approval where it matters.
- **Agent-to-agent systems** — Make capabilities, task status, and results understandable across independent services.

I wrote about the design choices in [Before you add another agent, draw the handoff](https://ristoholappa.com/blog.html). The site also has a [runnable A2A handoff example](https://ristoholappa.com/a2a-demo.html) with source and a test.

It runs in production on European infrastructure. Willit is co-funded by the EU via Oulun Seudun Leader ry (EAFRD 2023–2027).

Related work: [lahikalaa.fi](https://www.lahikalaa.fi/) for commercial fishermen and [willit24.com](https://willit24.com) for 24/7 pickup cabinets with temperature monitoring.
